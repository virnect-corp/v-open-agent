# 화면 시안 (2026-11-26)

ADR-0009, ADR-0010, ADR-0011 설계를 화면으로 옮긴 시안이다. TASK-45(관리자 페이지)와 TASK-46(시뮬 페이지)의 레이아웃, 문구, 상태 표시 기준으로 쓴다. 기능과 계약의 기준은 SPEC이다. 시안과 SPEC이 다르면 SPEC을 따르고 시안을 고친다.

- 캔버스: https://claude.ai/artifact/Fgexnkw3xErmXmnEwE2R3V
  - 비공개다. 다른 사람이 보려면 소유자가 캔버스의 Share 메뉴에서 공유해야 한다.
- 원본: `docs/design/mockups/2026-11-26/` (`*.dc.html` 5개, `canvas.json`)
  - 캔버스 런타임(`support.js`)이 있어야 그려지므로, 레이아웃과 문구 참고용이다. 화면 구현 코드에 그대로 가져다 쓰지 않는다.
- 영상과 이미지는 자리 표시자다. 실제 미디어 파일은 넣지 않았다.

## 화면

| 화면 | 원본 | 용도 | 반영한 결정 |
|---|---|---|---|
| 로그인과 가입 | `Login.dc.html` | 착용자 로그인과 가입(승인 대기 안내), 관리자 로그인과 첫 로그인 비밀번호 변경 | ADR-0011 §1~3, SPEC §7.1 계정 |
| 미션 초기 화면 | `Missions.dc.html` | 착용자: 게시된 미션 목록과 "이 미션으로 시작". 관리자: 편집 중과 보관 포함 목록, 새 미션, 편집, 복제, 삭제(보관), 편집 패널(감시 규칙, 근거 모델, 임계값, 검증, 게시) | ADR-0010 §1~4, 용어집, SPEC §7.1 미션 선택, §7.7 미션 |
| 시뮬 페이지 (글래스 뷰) | `Main.dc.html` | 미션 표시와 변경, 웹캠과 동영상 입력, 글래스 표시 영역의 HUD(경고 팝업, 전체 화면 깜빡임, 상태 표시줄), 판정 프레임 창(보낸 프레임 위 박스와 프레임 나이), 연결과 업로드 상태, 시나리오 상태, timing, 기록. 상태 8가지 미리보기 | ADR-0009 결정 1, 5, ADR-0010 §3, 5, 6, SPEC §7.4 HUD 표시 규칙과 상태 표시줄, §7.6 |
| 상태 표시줄과 HUD 축소 규칙 | `Status.dc.html` | 상태 표시줄 우선순위와 조건, 같은 경고의 기종별 표시(컬러와 전체 화면, 단색과 테두리, 단색과 깜빡임 없음) | ADR-0009 결정 5, SPEC §7.4 |
| 관리자 페이지 | `Admin.dc.html` | 모델 배치, 시나리오와 임계값(미션 편집기로 옮겨짐), 프레임 간격과 HUD 스타일, 이미지 한 장 시험, 변경 기록 | ADR-0009 결정 3, SPEC §7.7 |

## 시안 이후 바뀐 점 (구현 시 SPEC 기준으로 맞출 것)

- 관리자 페이지의 "시나리오와 임계값" 영역은 미션 편집기(`Missions.dc.html` 관리자 보기)로 옮긴다(ADR-0010). 관리자 페이지에는 모델 배치, 설정, 용량, 착용자 승인, 변경 기록이 남는다.
- 관리자 페이지 헤더의 "관리자 token 인증됨"은 관리자 계정 로그인으로 바뀐다(ADR-0011).
- 상태 표시줄에 "정원 초과"를 추가했다(SPEC §7.4 상태 0). `Status.dc.html` 정리표에는 아직 없다.
